## Precise location and statutory requests

Consent is the proposed basis for optional precise-location sharing: an informed button action followed by browser permission, with manual area entry available. Stop/manual edit clears coordinates and invalidates pending updates; it cannot recall a request already sent. Existing tests and synthetic-coordinate browser flows verified withdrawal/cancellation. Real device permission should be checked by the owner before launch; no real device coordinates were collected by the assistant. Keep the notice/implementation version, not a coordinate log, as evidence of the consent flow.

Processing necessary to meet statutory rights-request and privacy-complaint duties uses the applicable legal obligation. Distinguish routine enquiries from statutory cases; record the duty and deadline privately. The adopted minimal case-record schedule and complaint procedure apply.

## Storage/access decision

The clean Firefox report observed no app local/session storage, IndexedDB or Cache Storage entries and no cookies on captured Google API/photo requests. Both cookie modes passed. A Secure, HttpOnly session `nf_edge` cookie restricted private access; the earlier owner toolbar preference was separate. Normal HTTP caching occurred.

Assessment: no non-exempt tracking/storage was identified in the tested flows, so an additional consent banner is not justified by this inventory. Private authentication has a strictly necessary access-control purpose; cache use for transmitting/rendering requested assets is assessed separately from optional tracking. This does not establish that all non-cookie device access is absent, or that SDK telemetry has no secondary purpose. Legitimate interests is not a substitute for PECR consent. If tracking/non-exempt device access is identified, gate that activity before consent and support refusal/withdrawal. Recheck the final visitor configuration when private login/owner tools are removed, using [current ICO exceptions guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-the-exceptions/).
